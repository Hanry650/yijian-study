# 一建复习工具

一级建造师考试复习工具，支持填空题练习、错题本、学习模式和云端同步。

## 功能

- 📁 **Excel 导入**：上传 .xlsx 题库文件
- ✏️ **填空题模式**：直接在括号内输入答案
- 📚 **错题本**：自动记录错题，支持单独练习
- 📖 **学习模式**：直接查看答案，快速浏览记忆
- ☁️ **云端同步**：登录后跨设备同步数据（Supabase）
- 📦 **数据导出/导入**：JSON 格式本地备份

## 使用方式

访问：`https://你的用户名.github.io/yijian-study/`

## 技术栈

- 纯前端 HTML + CSS + JavaScript
- SheetJS 解析 Excel
- Supabase 云端数据库

## 部署说明

本项目为纯静态网页，可直接部署到 GitHub Pages、Vercel、Netlify 等平台。
